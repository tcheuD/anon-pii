# anon-pii v0.3.1

This patch fixes partial masking with certain custom regular expressions. It
requires `regex` 1.13.1 or newer and locks `regex-automata` to 0.4.16, incorporating
the upstream correction to reverse literal searches.

## What changed

- With the custom pattern `.abb|b`, input `zabb` previously left `za` visible
  followed by two tokens for the individual `b` matches. The corrected search
  selects the complete `zabb` span and replaces it with one token.
- Regressions cover both reverse-suffix and reverse-inner literal searches,
  including `(?:..acbb|b)a(?:c|d)` on `xzbacbbac`. They check the selected span,
  complete masking, mapping contents, and exact restoration.
- A Unicode prefix and percent-encoded source case (`🧪 za%62%62`) checks that
  matching the decoded value masks its entire original source spelling and
  restores those bytes exactly.
- The browser engine was rebuilt with the corrected dependencies. Native
  archive smoke checks now verify these custom patterns in preview and in
  actual child input, as well as exact restoration. Restoration alone could
  succeed while part of a sensitive value remained visible.

The reproduced failure uses custom recognizers. No impact on built-in patterns
has been demonstrated; this is not a claim that every possible pattern is
unaffected. Existing command interfaces and mapping formats are unchanged.

## Downloads and installation

The release workflow builds Linux x86_64 (Ubuntu 24.04/glibc), macOS Intel, and
macOS Apple Silicon archives, each containing `anon-pii`, README, and MIT
LICENSE. It publishes `SHA256SUMS` and SPDX/CycloneDX SBOMs with the archives.
Verify the archive checksum before extracting, then check `./anon-pii --version`.

Archives include `ner-lite,proxy,pdf`; enable heuristic names with `--ner`.
ML NER, OCR, and XLSX are excluded. Windows and Linux aarch64 have no prebuilt
archives. Source builds require Rust 1.88 or newer and should retain the checked-in
lockfile with `cargo install --locked --path . --features ner-lite`. The crate is
not published on crates.io.

Dependency advisory checks remain release gates under the
[dependency policy](https://github.com/tcheuD/anon-pii/blob/v0.3.1/docs/dependency-policy.md).
SBOMs describe the Cargo dependency graph, including optional features, rather
than only the code linked into each binary.

Detection can still miss sensitive values. Review prepared text before sharing
it. Existing privacy and behavior limits from
[v0.3.0](https://github.com/tcheuD/anon-pii/blob/v0.3.0/docs/releases/v0.3.0.md)
continue to apply.
