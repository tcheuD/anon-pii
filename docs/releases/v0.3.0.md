# anon-pii v0.3.0

Prepare a support ticket for AI, then restore the references in its reply.
This release adds a complete local browser workspace and a CLI starter that
demonstrates the handoff without an account or an AI service.

Try the [browser workspace](https://tcheud.github.io/anon-pii/#try) or follow the
[support-ticket guide](https://github.com/tcheuD/anon-pii/blob/v0.3.0/docs/support-ticket.md).

## What changed

- The browser workspace now supports explicit preparation, reviewed tokenized
  copy, pasted replies, restoration, and session clearing. One ticket owns one
  in-memory mapping. Editing the source, preparing again, clearing, or reloading
  discards the previous mapping and reply. Clipboard failures offer manual copy.
  Ticket contents are processed in the browser without AI calls or browser storage.
- Heuristic names now cover bounded introductions such as `je m'appelle Camille
  verneuil` on one line, including one lowercase surname. Fuller contained PERSON
  spans can complete a partial ML result without changing unrelated overlap priority.
- `FR_ADDRESS` detects a bounded street-number, street-type, street-name,
  metropolitan-postcode, and city shape. Unicode and source spelling survive
  token restoration. The recognizer does not validate a postal database.
- A fictional French ticket and local Python reply simulator demonstrate that
  the child receives tokens while the user sees restored name, email, and address
  references. The simulator intentionally displays its received input on stderr.
- SQL token mappings now retain doubled apostrophes and supported E-string
  escapes inside detected values, so restoring an address preserves the original
  literal spelling and quoting. Quoted CSV fields likewise retain doubled double
  quotes inside a matched value, including custom recognizers that span a quote.
  Other operators retain their existing behavior.
- Browser behavior is now a required CI gate against the actual checked-in WASM,
  including session isolation, clipboard fallback, literal text rendering, engine
  failure, responsive layout, and absence of ticket network requests or storage.

## Try the CLI starter

From a checkout of this release, with Python 3 and a release binary installed:

```bash
anon-pii --ner run --dry-run < demo/samples/support-ticket-fr.txt
anon-pii --ner run -- python3 demo/ticket-reply.py < demo/samples/support-ticket-fr.txt
```

This produces a deterministic local simulation, not an AI diagnosis. Review the
preview before using your own AI tool. Preview tokens belong to that invocation;
the actual run generates its own mapping. The browser keeps its prepared mapping
until the ticket session is cleared or replaced.

## Downloads

Linux x86_64 (Ubuntu 24.04/glibc), macOS Intel, and macOS Apple Silicon archives
include `anon-pii`, README, and MIT LICENSE. Download `SHA256SUMS`, verify your
archive, extract it, and check `./anon-pii --version`. Archives include
`ner-lite,proxy,pdf`; enable heuristic names with `--ner`. ML NER, OCR, and XLSX
are excluded. Windows and Linux aarch64 have no prebuilt archives.

Source installation requires Rust 1.88 or newer:

```bash
git clone --branch v0.3.0 --depth 1 https://github.com/tcheuD/anon-pii.git
cd anon-pii
cargo install --locked --path . --features ner-lite
```

The crate is not published on crates.io. SPDX and CycloneDX SBOMs include the
Cargo dependency graph, including optional features. Dependency advisory policy
is documented in [the repository](https://github.com/tcheuD/anon-pii/blob/v0.3.0/docs/dependency-policy.md).

## Limits and behavior

Detection can miss sensitive values. Names remain heuristic; arbitrary lowercase
or multiword lowercase names are not covered. The address rule excludes abbreviated
street types, overseas postcodes, and multiline addresses. Unhyphenated multiword
cities can be partly detected. Review the whole prepared ticket before sharing it.

The browser does not send tickets to an AI provider. Copying into another app is
your explicit handoff; clearing this workspace does not clear other apps or your
clipboard. Restored replies contain original sensitive values. Unknown or altered
tokens remain unchanged, and newly generated sensitive values are not redacted.

CLI `run` keeps its mapping in memory but is not a sandbox: child stderr,
filesystem, environment, and network access remain available. Standalone CLI
anonymization still persists mappings by default; those files contain original
values and need protection. Existing command interfaces remain available.

The original 62-case `debug-pii-v1` quality corpus is unchanged; the new ticket
scenarios are separately tested regressions, not a production accuracy estimate.
