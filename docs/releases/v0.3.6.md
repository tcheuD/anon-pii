# anon-pii v0.3.6

This patch brings compact UK IBAN detection without a financial keyword to the
native downloads. A ticket containing `value=GB82WEST12345698765432` now masks
the complete account reference before it reaches a child command. Native archives
through v0.3.5 leave this context-free example visible.

## What changed

A separate GB rule recognizes the complete 22-character national structure:
ASCII-case `GB`, check digits 02–98, four bank letters, and fourteen digits,
with word boundaries and a valid mod-97 checksum. The token remains
`IBAN_CODE` with score `0.7`; threshold `0.8` rejects it. Preparation and
restoration preserve the original spelling, Unicode prefixes, and surrounding
ticket text.

These structural guarantees apply to the new context-free rule. The existing
generic context-gated rule remains broader, grouped UK forms still require
context, grouped lowercase forms remain unsupported, and French IBANs retain
their classification. No dependency, mapping format, or CLI interface changes.

The browser engine already includes this detector improvement. Its local
workspace also offers selected-text protection for missed values and the
orange, black, and white interface. It remains account-free; ticket text and
mappings stay in the local session and are not saved to browser storage or sent
to a service.

## Verification and limits

Every extracted native archive must mask complete compact UK IBANs in both
preview and actual child input, then restore their exact original bytes.
Archive checks also cover invalid checksums, structural and boundary controls,
strict thresholds, and non-UK context gating. Existing support-ticket,
complete-password, wrapped-email, custom-regex, and API handoff checks remain
release gates, including no persisted transaction mapping.

The unchanged fictional maintainer corpus measures 45 TP, 0 FP, and 1 FN with
default features, threshold `0.5`, and no NER; see the
[versioned measurements](https://github.com/tcheuD/anon-pii/blob/v0.3.6/docs/quality.md).
The resolved compact GB case is now required by the baseline. These are
regression measurements, not customer adoption or production-accuracy estimates.
Detection can miss sensitive values; review prepared text before sharing it.

## Downloads and installation

The release provides Linux x86_64 (Ubuntu 24.04/glibc), macOS Intel, and macOS
Apple Silicon archives containing `anon-pii`, README, and MIT LICENSE, alongside
`SHA256SUMS` and SPDX/CycloneDX SBOMs. Download the archive and checksum file from
the same release, verify the checksum before extracting, and check
`./anon-pii --version` afterward.

Archives include `ner-lite,proxy,pdf`. Enable heuristic CLI name detection with
`--ner`; the local API is available with `./anon-pii api`. ML NER, OCR, and XLSX
are excluded. Windows and Linux aarch64 have no prebuilt archives. Source builds
require Rust 1.88 or newer; use `cargo install --locked --path . --features
ner-lite,proxy` for API support. The crate is not published on crates.io.

Dependency advisory checks remain release gates under the
[dependency policy](https://github.com/tcheuD/anon-pii/blob/v0.3.6/docs/dependency-policy.md).
SBOMs describe the Cargo dependency graph, including optional features.
